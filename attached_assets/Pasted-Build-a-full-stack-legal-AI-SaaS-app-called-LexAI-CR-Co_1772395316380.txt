Build a full-stack legal AI SaaS app called "LexAI CR" (Costa Rica legal assistant).
 
## TECH STACK
- Next.js 15 (App Router), TypeScript, Tailwind CSS
- shadcn/ui components, Lucide icons, Framer Motion animations
- Prisma ORM + Neon Postgres (with pgvector extension)
- NextAuth.js v4 for authentication (Google + Email/Password)
- OpenAI API (gpt-4o-mini for chat, text-embedding-3-small for RAG)
- Tiptap rich text editor
- @react-pdf/renderer for PDF export, docx library for Word export
- Dropbox Sign API (hellosign) for e-signatures
- Sonner for toast notifications

AI CHAT WITH RAG
Route: /dashboard (main page) POST /api/chat:

Load conversation history from DB (last 8 messages)
Generate embedding for user query (text-embedding-3-small)
Vector search on documents table using neon() direct SQL:
sql
SELECT fuente, materia, articulo, contenido,
  1 - (embedding <=> '[...]'::vector) as score
FROM documents
ORDER BY embedding <=> '[...]'::vector
LIMIT 5
Build context string from top results
Call gpt-4o-mini with system prompt as Costa Rica legal expert
Stream response back (useChat or manual SSE)
Save user + assistant messages to DB
POST /api/search-normativa (standalone search endpoint):

Receives { query, materias, topK }
Uses neon() tagged template SQL with pgvector
Returns { results: [{ fuente, materia, articulo, contenido, score }] }
Uses materias filter if provided: WHERE materia = ANY($materias::text[])

// Count existing versions
const count = await prisma.documentVersion.count({ where: { documentId: id } })
if (count >= 10) {
  // Delete oldest
  const oldest = await prisma.documentVersion.findFirst({
    where: { documentId: id }, orderBy: { createdAt: 'asc' }
  })
  await prisma.documentVersion.delete({ where: { id: oldest.id } })
}
